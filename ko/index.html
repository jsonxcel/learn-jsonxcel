JSON 입력, Excel 출력. 그 사이는 템플릿.

JsonXcel은 다국어 Excel 템플릿과 JSON 데이터 소스로 convert API 한 번으로 Excel/PDF를 생성합니다.

JsonXcel을 선택하는 이유

API 단순함을 유지하면서 보고서 레이아웃을 앱 코드에서 분리합니다.

JSON과 Excel 템플릿

디자이너가 통합 문서를 소유하고, 서비스는 구조화 JSON만 보냅니다. 마커로 필드를 연결하며 코드로 시트를 다시 그리지 않습니다.

5개 로케일 템플릿 폴더

동일한 template_name을 en-US / zh-CN / zh-TW / ja-JP / ko-KR에 둡니다. 각 convert에 language를 전달하세요.

하나의 convert 엔드포인트

POST /api/convert에 template_name, language, output_format, ds*를 보내 Excel 또는 PDF를 받습니다.

실제 비즈니스 문서

주문, 경비, 예산, 출하 안내 — 디자이너가 쓰는 수식·스타일·차트를 유지합니다.

단계적 학습 경로

첫 convert부터 확장, 필터, 다국어 송장까지 진행합니다.

운영 가능한 프로덕션

템플릿 폴더 스캔, 통합 문서 활성/비활성, 자체 인증·한도 뒤에 통합.

아키텍처 한눈에

업무 시스템은 JSON 네이티브를 유지합니다. JsonXcel이 템플릿 해석과 렌더링을 담당합니다.

  1. 1

    통합 문서 템플릿 준비

    Excel에 마커와 레이아웃을 두고 Templates/{language}/에 저장합니다.

  2. 2

    업무 JSON 생성

    ERP / SaaS / 스크립트가 ds / ds01을 만듭니다 — 앱 코드에 셀 좌표 없음.

  3. 3

    /api/convert 호출

    JsonXcel이 언어별 템플릿을 로드하고 데이터 소스를 바인딩한 뒤 ProcessTemplate을 실행합니다.

  4. 4

    Excel 또는 PDF 수신

    파일을 스트림하거나 이름·크기·경로 메타데이터를 저장합니다.

몇 분 만에 연동

fetch 한 번으로 JSON에서 지역화된 통합 문서를 생성할 수 있습니다.

  • • template_name · language · output_format
  • • ds / ds01… as JSON strings
  • • return_file_stream for download
API 가이드 읽기
fetch · /api/convert 
const res = await fetch(`${API_BASE}/api/convert`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    template_name: "lesson_m09_sales_order",
    language: "zh-CN",
    output_format: "excel",
    return_file_stream: true,
    return_file_name: true,
    ds: JSON.stringify({
      orderNo: "SO-2026-0412",
      customer: "Northwind",
      lines: [
        { sku: "A-100", qty: 2, price: 120 },
        { sku: "B-220", qty: 1, price: 890 }
      ]
    })
  })
});
const blob = await res.blob();
// download blob as .xlsx

평가자·통합 담당자를 위한 짧은 답.

다국어 Excel 템플릿에 JSON 데이터 소스를 주입하고 Excel 또는 PDF를 반환하는 Web Service입니다.
JsonXcel은 문서 생성을 위한 템플릿 + JSON + API 경로에 집중합니다. 튜토리얼은 그 경로를 가르치며 SDK 백과가 아닙니다.
최소 en-US, zh-CN, zh-TW, ja-JP, ko-KR. Templates/{language}/와 요청의 language 필드로 지정합니다.
가능합니다. 환경에서 JsonXcel.WebServer를 실행하고 템플릿 디렉터리를 가리킨 뒤 앱이나 Learn 사이트에서 /api/convert를 호출하세요.
Excel에 익숙한 누구나. 개발자가 JSON 계약을 정의하고, 디자이너가 시각 레이아웃과 현지화를 담당합니다.
