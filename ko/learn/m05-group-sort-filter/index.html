그룹·정렬·필터

G= / S= / F= 템플릿 속성.

  1. 그룹 집계
  2. 정렬
  3. 필터 연산자
  4. 복합 필터 조건
  • 그룹 집계 Use G=merge / G=repeat / G=list so repeated keys collapse or repeat while sibling fields expand.
  • 정렬 Sort expanding fields with S=asc or S=desc on a template marker.
  • 필터 연산자 F= expression filters — currently requires a table data source, not plain JSON ds.
  • 복합 필터 조건 AND / OR / NOT in F= expressions — blocked for JSON ds until table sources are supported.
