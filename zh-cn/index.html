架构一览

业务系统保持 JSON 原生；JsonXcel 负责模板解析与渲染。

  1. 1

    准备 Excel 模板

    在工作簿中放置标记与版式，存入 Templates/{language}/。

  2. 2

    产出业务 JSON

    ERP / SaaS / 脚本生成 ds、ds01 等载荷 — 应用代码不再写单元格坐标。

  3. 3

    调用 /api/convert

    JsonXcel 加载对应语言模板，绑定数据源并执行 ProcessTemplate。

  4. 4

    取得 Excel 或 PDF

    将文件流返回给用户，或保存名称/大小/路径等元数据。

几分钟完成接入

一次 fetch 即可从 JSON 生成本地化工作簿。

  • • template_name · language · output_format
  • • ds / ds01… as JSON strings
  • • return_file_stream for download
阅读 API 指南
fetch · /api/convert 
const res = await fetch(`${API_BASE}/api/convert`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    template_name: "lesson_m09_sales_order",
    language: "zh-CN",
    output_format: "excel",
    return_file_stream: true,
    return_file_name: true,
    ds: JSON.stringify({
      orderNo: "SO-2026-0412",
      customer: "Northwind",
      lines: [
        { sku: "A-100", qty: 2, price: 120 },
        { sku: "B-220", qty: 1, price: 890 }
      ]
    })
  })
});
const blob = await res.blob();
// download blob as .xlsx
