カリキュラム

初めての convert から実践レポートまで、段階的に JsonXcel を学べます。

各レッスンにはサンプル JSON、テンプレート、静的プレビュー、ローカル API（http://127.0.0.1:5000）向けデモがあります。

詳細な技術本文は当面英語／簡体字が基準です。マーカー・JSON キー・template_name は全言語で同一です。

JsonXcel を選ぶ理由 から始めてください。

  • データソースと API ds / ds01、Excel と PDF、ストリームとメタデータ。
  • ページネーションと印刷 改ページとグループヘッダー。
  • グループ・並べ替え・フィルタ G= / S= / F= テンプレート属性。
  • テンプレート基礎 Mustache、ネスト、式、インライン標記。
  • なぜ JsonXcel か テンプレートと JSON の分離を理解してから API を呼びます。
  • レイアウトとスタイル テーブル、グラフ、条件付き書式、画像。
  • 拡張・コンテキスト・範囲 リスト拡張と主従コンテキストを制御します。
  • 実践サンプル 業務向けのエンドツーエンド帳票。
  • 多言語テンプレート 同一 template_name を言語フォルダに配置。
