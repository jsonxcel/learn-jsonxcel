Curriculum

Progressive JsonXcel lessons from first convert call through real-world reports.

Each lesson includes sample JSON, a downloadable template, static previews, and an interactive convert panel (local API on http://127.0.0.1:5000).

Start with Why JsonXcel or jump to Your first convert call.

  • Why JsonXcel Understand template + JSON decoupling before writing API calls.
  • Template markup basics Mustache markers, nested paths, expressions, and inline text.
  • Data sources and API ds / ds01 payloads, Excel vs PDF, and stream vs metadata responses.
  • Expansion, context, and range Control how list fields expand, how master-detail context works, ranges, and fill modes.
  • Group, sort, and filter Template properties G=, S=, and F= for shaping list output.
  • Layout and style Tables, charts, conditional formatting, and images.
  • Pagination and print Page breaks and repeating group headers.
  • Multilingual templates One template_name across language folders.
  • Practical reports End-to-end business workbooks.
