JSON を入れて、Excel を出す。間はテンプレート。

JsonXcel は多言語 Excel テンプレートと JSON データソースから、1 回の convert API で Excel / PDF を生成します。

JsonXcel が選ばれる理由

API の単純さを保ったまま、帳票レイアウトをアプリコードから切り離します。

JSON と Excel テンプレート

デザイナーがブックを所有し、サービスは構造化 JSON を送るだけ。マーカーでフィールドを結び、コードでシートを描き直しません。

5 ロケールのテンプレートフォルダ

同じ template_name を en-US / zh-CN / zh-TW / ja-JP / ko-KR に配置。各 convert で language を渡します。

ひとつの convert エンドポイント

POST /api/convert に template_name、language、output_format、ds* を渡し、Excel または PDF を受け取ります。

実務のビジネス帳票

受注、経費、予算、出荷案内 — デザイナーが使う数式・スタイル・グラフをそのまま。

段階的な学習パス

最初の convert から展開、フィルタ、多言語請求書まで進めます。

本番運用に耐える

テンプレートフォルダのスキャン、ブックの有効／無効、独自の認証とレート制限の背後で統合。

アーキテクチャ概要

業務システムは JSON ネイティブのまま。JsonXcel がテンプレート解決と描画を担当します。

  1. 1

    ブックテンプレートを用意

    Excel にマーカーとレイアウトを置き、Templates/{language}/ に保存します。

  2. 2

    業務 JSON を出す

    ERP / SaaS / スクリプトが ds / ds01 を生成 — アプリコードにセル座標は不要。

  3. 3

    /api/convert を呼ぶ

    JsonXcel が言語別テンプレートを読み込み、データソースをバインドして ProcessTemplate を実行します。

  4. 4

    Excel または PDF を受け取る

    ファイルをストリームするか、名前・サイズ・パスなどのメタデータを保存します。

数分で統合

1 回の fetch で JSON からローカライズ済みブックを生成できます。

  • • template_name · language · output_format
  • • ds / ds01… as JSON strings
  • • return_file_stream for download
API ガイドを読む
fetch · /api/convert 
const res = await fetch(`${API_BASE}/api/convert`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    template_name: "lesson_m09_sales_order",
    language: "zh-CN",
    output_format: "excel",
    return_file_stream: true,
    return_file_name: true,
    ds: JSON.stringify({
      orderNo: "SO-2026-0412",
      customer: "Northwind",
      lines: [
        { sku: "A-100", qty: 2, price: 120 },
        { sku: "B-220", qty: 1, price: 890 }
      ]
    })
  })
});
const blob = await res.blob();
// download blob as .xlsx

コード描画シート vs JsonXcel

レイアウト変更のためにエンジニアリングスプリントを払わない。

観点 コードでセルを描く JsonXcel テンプレート
レイアウトの所有者 開発者がソースでピクセルと結合を調整 業務側が慣れ親しんだ xlsx を編集
ローカライズ UI コードで分岐や文字列表を増やす Templates/{lang} を差し替え、API は同じ
変更速度 列幅調整にもデプロイが必要 テンプレート差し替えのみ、アプリ再ビルド不要
必要なスキル 表ロジックが C# / Java に埋もれる Excel 習熟度 + JSON 契約
