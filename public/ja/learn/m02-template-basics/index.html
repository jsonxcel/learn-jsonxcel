テンプレート基礎

Mustache、ネスト、式、インライン標記。

  1. Mustache フィールド
  2. ネストと配列展開
  3. 式と数式セル
  4. インライン記法
  • Mustache フィールド Bind flat JSON fields to Excel cells with {{field}} markers and convert through JsonXcel.
  • ネストと配列展開 Reach into nested JSON with dotted paths, and expand array rows with collection field markers.
  • 式と数式セル Mix JSON-bound values with Excel formulas so totals recalculate after convert.
  • インライン記法 Embed {{fields}} inside a sentence so one cell mixes static copy and bound values.
