Architecture at a glance

Your systems stay JSON-native. JsonXcel owns template resolution and rendering.

  1. 1

    Prepare a workbook template

    Place markers and layout in Excel; store under Templates/{language}/.

  2. 2

    Emit business JSON

    ERP, SaaS, or scripts produce ds / ds01 payloads — no cell coordinates in app code.

  3. 3

    Call /api/convert

    JsonXcel loads the language-specific template, binds data sources, and runs ProcessTemplate.

  4. 4

    Receive Excel or PDF

    Stream the file to users or store metadata (name, size, path) for your workflow.

Integrate in minutes

A single fetch is enough to generate a localized workbook from JSON.

  • • template_name · language · output_format
  • • ds / ds01… as JSON strings
  • • return_file_stream for download
Read the API guide
fetch · /api/convert 
const res = await fetch(`${API_BASE}/api/convert`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    template_name: "lesson_m09_sales_order",
    language: "zh-CN",
    output_format: "excel",
    return_file_stream: true,
    return_file_name: true,
    ds: JSON.stringify({
      orderNo: "SO-2026-0412",
      customer: "Northwind",
      lines: [
        { sku: "A-100", qty: 2, price: 120 },
        { sku: "B-220", qty: 1, price: 890 }
      ]
    })
  })
});
const blob = await res.blob();
// download blob as .xlsx
